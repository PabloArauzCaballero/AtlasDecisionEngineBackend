# Evidencia de configuración de asistencia

Esta carpeta conserva auditorías, inventarios, selección de extensiones y guías generadas durante
la configuración del entorno de desarrollo asistido. Su valor de negocio es demostrar cómo se
controló el proceso de cambio; su valor de sistema es registrar versiones, reglas y limitaciones
del entorno usado para modificar el backend.

Los documentos son evidencia fechada. No definen comportamiento del servicio ni reemplazan
`CLAUDE.md`, `.claude/rules/`, los tests o la documentación de arquitectura vigente.
