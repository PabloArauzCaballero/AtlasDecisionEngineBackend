# Seguimiento documental

Esta carpeta está reservada para bitácoras temporales de trabajo que necesiten conservar evidencia
sin convertirse en contratos permanentes. A nivel de negocio hace visibles avance y bloqueos; a
nivel de sistema separa notas de ejecución de la documentación normativa y arquitectónica.

Una bitácora cerrada debe moverse a un reporte fechado o eliminarse mediante una revisión
controlada. El estado vigente siempre vive en `docs/README.md` y en los gates automatizados.
