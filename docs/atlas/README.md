# Documentos de integración Atlas

Esta carpeta está reservada para contratos y decisiones específicas de integración con el resto
del ecosistema Atlas. A nivel de negocio evita mezclar políticas del motor con acuerdos entre
productos; a nivel de sistema ofrece un límite estable para mapeos de identidad, variables y
eventos externos.

Actualmente no contiene contratos adicionales. Un documento nuevo debe identificar sistema
productor, consumidor, dueño, clasificación de datos, versionado y estrategia de compatibilidad.
