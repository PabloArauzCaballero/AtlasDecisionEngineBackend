# Datos de siembra

Esta carpeta define catálogos, grafo, casos y workflow de demostración como datos versionados. A
nivel de negocio hace visible la lógica del ejemplo y sus supuestos; a nivel de sistema separa
declaraciones deterministas de la orquestación y permite probar checksums, rutas y salidas.

Los valores son demostrativos, no políticas aprobadas. Cada variable documenta dueño, origen,
clasificación y contrato; los helpers no abren conexiones ni leen secretos salvo los clientes
bootstrap expresamente configurados.
