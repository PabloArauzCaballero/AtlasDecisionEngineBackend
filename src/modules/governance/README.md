# Gobierno y aprobaciones

Este módulo convierte revisión humana en estados verificables. A nivel de negocio implementa QA,
Riesgo y Compliance con segregación de funciones; a nivel de sistema crea solicitudes/pasos,
registra decisiones/evidencia y publica eventos dentro de la transacción.

El autor no puede autoaprobar y una versión no avanza hasta satisfacer todos los pasos requeridos.
Los endpoints de lectura y decisión tienen roles distintos.
