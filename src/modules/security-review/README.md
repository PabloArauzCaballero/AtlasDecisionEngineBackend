# Vista de revisión de seguridad

Este módulo agrega evidencia técnica y de gobierno para el equipo de Seguridad. A nivel de negocio
facilita aprobar, rechazar o pedir cambios con contexto; a nivel de sistema reúne versión, grafo,
scripts, validaciones, aprobaciones y hallazgos sin duplicar las fuentes de verdad.

La exportación es una fotografía de revisión tenant-scoped. No sustituye SAST, pentest ni la
decisión formal almacenada por Gobierno.
