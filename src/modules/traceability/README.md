# Trazabilidad de objetivos y políticas

Este módulo relaciona objetivos, requisitos, artefactos y suites. A nivel de negocio permite
explicar qué control cubre cada decisión y dónde falta evidencia; a nivel de sistema mantiene links
tenant-scoped, matriz de cobertura y auditoría transaccional.

Los enlaces sólo aceptan versiones/suites del mismo tenant. La matriz es una vista de cobertura, no
una aprobación automática de la política.
